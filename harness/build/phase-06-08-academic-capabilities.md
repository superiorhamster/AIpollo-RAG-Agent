Implement FR-06, FR-07, FR-08 and FR-09 using the interaction and citation contracts. Extend objectives with capability-specific output types. The model gateway receives an output template and only the selected evidence. Results remain private until an Owner or Editor saves an artifact explicitly.

Artifact owns generated content and export. Store the creating actor, source run, output type, and immutable citations. Access checks apply current workspace membership and source availability. Owners manage artifacts for the workspace, Editors manage their own artifacts, and Viewers read and download. Keep personal notes and highlights anchored to the document, with Document responsible for their storage. Workspace owns reference collections and the read-only Crossref discovery integration.

Add owned artifact tables and additive migrations for notes and references. Existing conversations and plans use the general answer format. Verify read/write scope, duplicate publication, source deletion, and export content. Keep stored artifacts and annotations when rolling back application images.
